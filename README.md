# Vertex Realty — Landing

Propuesta de landing corporativa para Vertex Realty SpA (Viña del Mar).

Sitio estático de un solo archivo (`index.html`), sin dependencias de build. Publicado con GitHub Pages desde la rama `main`.

Las fotos y fichas de propiedades se enlazan desde la plataforma de publicación actual del cliente (toppropiedades.cl / vertexrealty.cl).
